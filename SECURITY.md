# Security policy

Deskchirp is currently in preview. Security fixes target the latest preview; older development builds may not receive fixes.

Please use [GitHub's private vulnerability reporting](https://github.com/geekynasir/deskchirp-discord/security/advisories/new) for suspected credential exposure, unwanted sharing, account-isolation failures, or publishing-permission bypasses. Include the version, operating system, steps to reproduce, and a small example using fictional data. Please do not open a public issue containing sensitive details.

Never include Discord account tokens, T3 access tokens, linking codes, saved device credentials, conversations, or private service addresses. Deskchirp needs a public Discord application ID, not your Discord password or account token.

The optional linking service is intended for a private HTTPS network. It is not a public hosted service. See [hosting guidance](coordination/README.md) and [privacy](docs/privacy.md) before running it.
