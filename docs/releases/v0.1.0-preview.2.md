# Deskchirp for Discord — simpler setup

Open Discord and your developer app, then turn on **Share on Discord**. Deskchirp’s Discord application is included; no Developer Portal registration, token or password is needed.

For task and helper counts, choose **Allow T3 activity**. Deskchirp finds a normal local T3 Code installation and opens its required read-only approval. Counts turn on after approval and the saved connection returns on later launches. Manual T3 addresses, custom Discord application IDs and optional artwork are under **Advanced**. Remote/custom installations retain an address override. If multiple local environments answer, Deskchirp asks you to choose.

Existing blank application IDs upgrade automatically. Custom IDs, sharing, pause and linked-computer choices are preserved. Sharing remains off until you enable it. Discovery reads only public local runtime-address metadata; it never opens T3’s encrypted catalog, stored credentials or conversations. No approval window opens repeatedly in the background.

## Downloads

Choose `macos-arm64` for Apple Silicon, `macos-x86_64` for Intel, or `windows-x64` for Windows. Extract the entire download. Mac users can move Deskchirp.app to Applications; Windows users run Deskchirp.exe with its DLLs and subdirectories kept together. Setup guides, license notices, source/build information and SHA256SUMS are included. The private linking-service source is a separate download.

## Preview limits

Mac builds have an ad-hoc signature and are not notarized. Windows builds are unsigned. These are portable development bundles, not installers. Real-device Discord display, T3 browser approval, lock/sleep and multi-computer handoff still need hands-on acceptance. Follow me still requires a private linking service; no public service is hosted. Artwork is off by default because the shared Discord application has no uploaded icons yet.

T3 approval may ask for a pairing code and currently expires after 30 days. Remote environment selection and custom data folders may require Advanced. If T3’s local port changes, clear the previous address and reconnect. Claude Desktop and Codex Desktop remain app-name-only. Conversations, window titles, projects, model names, code and file paths are not published.
