# Deskchirp for Discord — follows your T3 Code connections

## Every T3 Code connection, without setup (Windows)

If your tasks run on a server or another computer, you no longer need to copy its address into Deskchirp. Once **Allow T3 activity** is on, Deskchirp uses the connections saved in your T3 Code desktop app. Each environment appears under **T3 environments** marked **From T3 Code** and connects read-only by itself, with no browser approval. Add or remove a connection in T3 Code and Deskchirp follows within about a minute.

- If an environment’s address stops answering, for example when you leave the network it was on, Deskchirp switches to another address T3 Code has for it.
- If your card shows token usage, followed environments get token usage too.
- Removing an environment or its token access here sticks. **Disconnect** also stops following, so nothing signs back in.
- Turn off **Use T3 Code’s connections** to stop this.

Deskchirp opens T3 Code’s encrypted connection list with your Windows account. For each environment, it uses T3 Code’s saved sign-in once, only with that environment, to create a one-time read-only pairing code. The pairing shows up in T3’s **Settings → Sharing & access** as **Deskchirp**. T3 Code’s own sign-in is never saved, logged or sent anywhere else. See [Connect T3](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/connect-t3.md) and [Privacy](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/privacy.md).

Connections that only go through T3 Connect, SSH connections, and plain `http://` addresses on another computer can’t be followed yet. Deskchirp names them under the switch; add them by hand if you can reach them another way.

## Updating

Installed preview 4 copies download this update by themselves and offer **Restart now**. Or download **Deskchirp-0.1.0-preview.5-windows-x64-setup.exe** and open it.

## Preview limits

Following T3 Code’s connections is Windows only; Mac works as before. Windows builds and the installer are unsigned, so Windows may show an "unrecognized app" warning. Mac builds are ad-hoc signed and not notarized, and don’t update themselves yet. The pairing-code sign-in was checked against a real T3 Code 0.1.6 server; following a real desktop app’s connections still needs hands-on checks. Conversation contents, window titles, real project names, code and file paths are never published.
