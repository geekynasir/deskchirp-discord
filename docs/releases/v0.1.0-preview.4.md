# Deskchirp for Discord — one-click Windows install, remote T3 and card controls

## Windows: one click, then automatic updates

Download **Deskchirp-0.1.0-preview.4-windows-x64-setup.exe** and open it. There's no wizard any more: a Deskchirp window shows progress for a few seconds, then the app opens. It installs for your Windows account with its runtimes and needs no administrator access.

If you installed preview 3, the new installer closes and removes it. Settings and saved sign-ins carry over.

From now on Deskchirp updates itself. It checks GitHub Releases every few hours, downloads new versions in the background, and shows **Update ready → Restart now**. If you don't restart, the update installs the next time Deskchirp opens. **Settings → Updates** shows your version, lets you check now, and turns automatic downloads off. Only the version check goes to GitHub; nothing about your activity is sent.

The Windows installer is built with [Velopack](https://velopack.io). The portable ZIP is still available and doesn't update itself.

## Tasks on another computer

If your T3 tasks run in a remote environment, add it under **T3 environments → Add environment** with the MCP URL from T3 Code. Deskchirp follows every environment in the list and combines their counts. Before, it followed only this computer's T3, so remote work showed as just **Using T3 Code**.

## Choose what your card shows

- **Card shows:** app only, workload (`2 tasks · 4 helpers`), or usage (`842K tokens today`).
- **Usage:** tokens today, this session or for a pinned task; how full a task's context is; optional estimated API cost.
- **Card options:** status or tool badge, project alias, model, elapsed timer, playful wording and up to two buttons.
- **Projects:** hide projects from counts, or pin one project or task.
- **Preview:** settings list every field before it's sent and warn when Discord may cut a line off.

Token usage needs one extra permission per environment: run `t3 pair --scope orchestration:read --scope diagnostics:read --label Deskchirp` on that computer and paste the code into Deskchirp. It also allows reading diagnostics and task details; Deskchirp uses it only for token counts and never stores or sends conversation content. See [Connect T3](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/connect-t3.md).

New working, waiting and idle status badges come from the `artwork-v2` artwork tag.

## Preview limits

Windows builds and the installer are unsigned, so Windows may show an "unrecognized app" warning. Mac builds are ad-hoc signed and not notarized, and don't update themselves yet. CI checks both native builds, the installer replacing a real preview 3 install, an in-place update, Start launch, reinstall and uninstall. Per-task and session token counts, the context percentage and real Discord rendering still need hands-on checks. Conversation contents, window titles, real project names, code and file paths are never published.
