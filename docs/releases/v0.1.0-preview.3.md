# Deskchirp for Discord — installer, artwork and minimized T3

## Windows: one installer

Download **Deskchirp-0.1.0-preview.3-windows-x64-setup.exe**, open it, and follow setup. Launch Deskchirp from Start. The per-user installer includes the runtimes, a Start shortcut, optional desktop shortcut, and an uninstaller in Windows Installed Apps. No administrator access or extra runtime download is needed. Quit Deskchirp before upgrading. Settings and saved connections are retained when uninstalling; disconnect or unlink in the app first to remove saved connections.

The separately labelled `windows-x64-portable.zip` is optional. Normal users do not need to unzip or manage DLLs.

## Artwork included

Deskchirp now has its own native app icon and branded setup wizard. T3 Code, Claude, Codex, Antigravity, Cursor, OpenCode and Grok images are bundled. Card artwork is on by default and uses fixed public URLs fetched by Discord, so users do not upload assets. The separate artwork ZIP includes PNGs and Deskchirp's SVG/ICO/ICNS sources. The Discord application icon remains an owner-managed setting in the Developer Portal.

## T3 can stay minimized

T3 no longer needs focus. Fresh unfinished T3 work stays visible in the background; otherwise the active supported developer app wins. If no supported developer app is active, an open T3 app keeps its app-name card. Closing T3 clears its task counts. Sharing off, pause, screen lock, sleep and linked-computer grants still control publication.

## Preview limits

Windows builds and the installer are unsigned. Mac builds are ad-hoc signed and not notarized. CI checks native builds, installation, Start launch, an older-version installer fixture, upgrade and uninstall. Real-device Discord rendering, T3 sign-in, lock/sleep and multi-computer acceptance still need hands-on checks. Follow me still requires a private linking service. No conversation contents, window titles, projects, model names, code or private file paths are published.
