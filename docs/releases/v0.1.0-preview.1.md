# Deskchirp for Discord — first preview

Share what you're working with on Discord, from a native Mac menu-bar or Windows tray app.

## Included

- App-only status for T3 Code, Claude Desktop, and Codex Desktop.
- Optional T3 Code connection: show the busiest agent tool and separate task/helper counts, with read-only browser approval.
- Follow me: link your computers and select the one you most recently used. Requires your own private linking service; no public service is hosted.
- Optional Discord artwork, sharing controls, and clear previews. Sharing starts off.

## Choose a download

| Computer | Download |

| Apple Silicon Mac, macOS 13+ | `Deskchirp-0.1.0-preview.1-macos-arm64.zip` |
| Intel Mac, macOS 13+ | `Deskchirp-0.1.0-preview.1-macos-x86_64.zip` |
| Windows 10 build 19041+ / Windows 11, x64 | `Deskchirp-0.1.0-preview.1-windows-x64.zip` |

Extract the Mac download and move `Deskchirp.app` to Applications. Extract the entire Windows download and run `Deskchirp.exe`; keep its DLLs and folders together. Setup guides, license notices, artwork, and source/build information are included. `SHA256SUMS` lets you verify the downloads.

Run Discord desktop on the same computer. Create an application in the [Discord Developer Portal](https://discord.com/developers/applications), copy its public Application ID into Deskchirp, and turn on sharing. No bot token or client secret is needed. Read [setup](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/trying-builds.md), [T3 connection](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/connect-t3.md), and [linked computers](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/computers.md).

## Preview limits

These are portable development bundles, not installers. Mac builds have an ad-hoc signature and are not notarized; Windows builds are unsigned. macOS or Windows may ask you to approve the download. Only open builds you trust; do not disable system protections globally.

CI builds and tests both Mac architectures, the Windows app, the portable core, and the private linking server. Automated handoff tests use real HTTP with simulated input. Real-device Discord display, mixed-computer switching, accessibility, lock/sleep, secure storage, and clean-machine installation still need hands-on acceptance. A computer handoff can take about twenty seconds plus network delay. See [verification status](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/validation.md).

Conversations, projects, model names, window titles, and file paths are not published. Claude Desktop and Codex Desktop currently share only the app name. Internal helpers that T3 does not expose as child threads are not counted. No token or cost display is included.
