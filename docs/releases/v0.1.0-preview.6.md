# Deskchirp for Discord — reaches the rest of your T3 Code environments over SSH

## T3 Connect and SSH environments, without pairing codes (Windows)

Preview 5 followed the connections saved in your T3 Code desktop app, but skipped the ones T3 Code reaches only through T3 Connect or over SSH. Deskchirp now reaches those with your own SSH, so every environment in T3 Code shows up under **T3 environments** and connects read-only by itself. You don’t create or copy any pairing codes.

- For an SSH connection, Deskchirp uses the machine T3 Code saved.
- For a T3 Connect one, it asks the machines in your `~/.ssh/config` and your own Linux and Mac machines in Tailscale which T3 environment each one runs.
- On that machine, T3 Code’s own `t3` command creates a five-minute read-only pairing code. Deskchirp then signs in through an SSH tunnel to a fixed local port. The pairing shows up in T3 as **Deskchirp**.
- The tunnel stays open while the environment is followed. It reopens when it drops, and closes when you remove the environment or turn following off.

This needs `ssh <machine>` to sign in without a password prompt, with a key or ssh-agent, using the built-in Windows OpenSSH. Deskchirp never asks for a password and never starts or stops T3 Code there. If a machine can’t be reached, isn’t running T3 Code, or has no `t3` command, Deskchirp says so on the environment and tries again by itself. It reads only T3’s environment id and port on each machine, never its secrets or conversations. See [Connect T3](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/connect-t3.md#over-ssh) and [Privacy](https://github.com/geekynasir/deskchirp-discord/blob/main/docs/privacy.md).

## Updating

Installed preview 4 and 5 copies download this update by themselves and offer **Restart now**. Or download **Deskchirp-0.1.0-preview.6-windows-x64-setup.exe** and open it.

## Preview limits

Following T3 Code’s connections, including over SSH, works only on Windows; Mac works as before.

- Windows builds and the installer are unsigned, so Windows may show an "unrecognized app" warning.
- Mac builds are ad-hoc signed, not notarized, and don’t update themselves yet.
- The SSH scripts were checked against a real T3 Code server, but the full tunnel and sign-in from Windows still needs hands-on checks.

Conversation contents, window titles, real project names, code and file paths are never published.
