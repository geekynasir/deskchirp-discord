# Microsoft Visual C++ runtime

Windows downloads include the x64 Visual C++ runtime files from the Microsoft Visual Studio 2022 build toolchain, installed beside Deskchirp (app-local deployment). These Microsoft components are not covered by Deskchirp’s MIT license.

Microsoft’s applicable Visual Studio / Visual C++ runtime license and redistribution terms govern these files:

- https://visualstudio.microsoft.com/license-terms/vs2022-cruntime/
- https://learn.microsoft.com/cpp/windows/redistributing-visual-cpp-files
- https://learn.microsoft.com/cpp/windows/walkthrough-deploying-a-visual-cpp-application-to-an-application-local-folder
